# English Companion

A planned Windows desktop app for everyday English reading and learning, with a focus on American English and practical conversation.

## Project status

The interaction and visual design have been reviewed. The Windows app and live dictionary integration have not yet been implemented. This page describes the planned project; there is no downloadable release yet.

## Planned experience

- Start the app manually, then look up selected English text or type a word, phrase, or sentence.
- See the essential meaning first in a small window that adjusts to its content. Pin the window when needed.
- For words, view pronunciation, part of speech, definitions, and available pronunciation audio.
- Expand the result to see examples, everyday conversational expressions, and usage notes, with Chinese translations and explanations.
- Keep local lookup history and saved entries.
- Fully quit the app when its main window is closed.

## Dictionary and learning content

The planned integration uses the official Merriam-Webster Learner's Dictionary API for available dictionary entries and word pronunciation audio, subject to its terms and approval. API access is being arranged.

DeepSeek will provide AI-assisted Chinese explanations, sentence translations, and conversational learning material. These additions will be labeled separately from dictionary content. AI-generated material can contain errors and will require evaluation during development.

For phrases or sentences without dictionary recordings, pronunciation may use an installed American English voice in Windows. This would be labeled as synthesized speech.

## Initial use

The initial project is intended for non-commercial personal learning and a small group of friends, approximately five users. It will not distribute a bundled dictionary. Any later distribution or commercial use will require reviewing the relevant API licensing terms.

## API credentials

Dictionary and AI API credentials must be configured locally by the app user and must never be committed to this repository.
